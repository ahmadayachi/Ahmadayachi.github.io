## Project
### Doubt it 
![in_game_screen_shot](/assets/ingame_screen_shots.png)
- **Description**: "Doubt it" is a card game that can be played by 2-8 players. Each player's objective is to get rid of all cards dealt to them. The last player with cards in their hand is the loser.
- **Technologies Used**: Unity, C#, Photon Fusion SDK, Google AdMob SDK, Google Play Games Services SDK.
- **My Role**: Unity Game Developer. 
- **Main Responsibilities**: 
  - *Game Logic Development*: Implemented core gameplay mechanics using a structured approach for managing game states and centralizing game logic.
  - *Multiplayer Networking*: Implemented a Host/Client network architecture using the Photon Fusion SDK for online multiplayer functionality.  
  - *Testing*: Used unit testing to validate code in isolation and automated testing to create various scenarios to test different stages of the game. With Photon Fusion’s multi-peer mode, I was able to test multiple peers within the Unity editor.
  - *SDK Integration*: Integrated Google AdMob, Google Play Games Services, and PlayFab following official documentation.
  - *UI/UX Design & Audio*: Contributed to the implementation of user interface/user experience design and integrated sound effects/music.
